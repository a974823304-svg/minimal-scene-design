# 极简场景设计 Skill

`minimal-scene-design` 用于设计、生成、分析和优化极简视觉场景。它不绑定蓝天白墙、黑白灰、建筑摄影或无人空间，可在真实摄影、生活观察、自然地景、建筑空间、概念艺术和抽象图形之间选择适合当前要求的方向。无需掌握提示词或专业参数，只用自然语言描述想要的画面即可。

## 快速开始

直接生成图片：

```text
使用 $minimal-scene-design，直接生成一张海边极简美术馆，安静、高级、有大片留白。
```

只生成提示词：

```text
使用 $minimal-scene-design，帮我写一段海边极简美术馆的生图提示词。
```

最简单的描述公式：

```text
想画什么 + 在什么地方 + 什么感觉
```

不确定构图、光线、颜色或镜头时可以不写，skill 会自动选择合理方案。

## 主要能力

- 根据一句简单描述直接设计或生成极简场景。
- 创建建筑、室内、自然景观、艺术装置、产品和静物空间。
- 分析参考图的构图、空间、光影、材质和色彩规律。
- 持续收录用户照片素材，区分候选偏好与稳定审美倾向。
- 根据任务在多种极简风格家族之间路由，避免固定配色和固定题材。
- 保留参考图的视觉语言，同时替换主体或环境。
- 优化已有图片或提示词，减少杂乱、塑料感和廉价 CG 感。
- 输出中文或英文生图提示词及必要的负面提示词。
- 设计手机壁纸、电脑壁纸、社交媒体竖图、横向地景等画幅。

## 常用示例

### 从零生成

```text
使用 $minimal-scene-design，直接生成一张雪地里的黑色小屋，安静、孤独、像艺术摄影。
```

```text
使用 $minimal-scene-design，直接生成一张巨大白色空间中的红色圆球，有强烈阳光和几何阴影。
```

```text
使用 $minimal-scene-design，直接生成一张沙漠里的弧形建筑，温暖、宁静，适合手机壁纸。
```

```text
使用 $minimal-scene-design，直接生成一张颜色明亮的极简生活摄影，不要蓝天白墙模板，你根据主体选择构图。
```

### 使用参考图

上传图片后说：

```text
使用 $minimal-scene-design，参考这张图的构图和光线，改成海边的极简美术馆，直接生成图片。
```

```text
使用 $minimal-scene-design，保留这张图的大面积留白和小主体，把雪地改成沙漠，其他感觉不变。
```

### 修改生成结果

```text
其他不变，让主体更小、留白更多。
```

```text
其他不变，把阳光改成阴天柔光，颜色更冷一点。
```

```text
其他不变，去掉人物和文字，墙面增加真实的粗糙质感。
```

## 默认设计方式

当用户没有指定专业参数时，skill 会默认：

- 保留一个清晰的主视觉主体。
- 选择一个明确主关系，并判断应使用大面积留白、块面平衡还是满幅秩序。
- 保持统一、合理的光源和阴影。
- 先选择观察式摄影、设计化摄影、概念空间或抽象图形，再匹配材质与透视。
- 控制装饰、颜色和次要元素的信息量。
- 普通场景采用 4:5，横向地景采用 3:2，手机壁纸采用 9:16。

极简不等于只能使用黑白灰，也不等于永久禁止人物、家具、植物、生活痕迹、鲜艳颜色或渐变。这些元素可以作为尺度、焦点、色块或情绪锚点，但会被控制在清晰的视觉层级中。

## 输出方式

- 用户说“直接生成、做一张、出一张”时，优先直接生成图片。
- 用户说“写提示词、给我 prompt”时，只输出可直接使用的提示词。
- 当前环境没有图像生成能力时，输出完整提示词供其他图像模型使用。
- 零基础模式默认保持简洁，不先展示冗长的专业分析。
