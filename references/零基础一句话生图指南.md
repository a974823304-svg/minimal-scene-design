# 零基础一句话生图指南

不需要学习提示词，也不需要知道镜头、光圈、材质等专业术语。选中 `$minimal-scene-design` 后，用日常说话的方式描述想要的图片即可。

## 最简单的用法

直接说：

```text
使用 $minimal-scene-design，直接生成一张海边极简美术馆，安静、高级、有大片留白。
```

只想获得提示词，不立即出图时说：

```text
使用 $minimal-scene-design，帮我写一段海边极简美术馆的生图提示词。
```

区别只有一句话：说“直接生成一张”就是要图片；说“帮我写提示词”就是只要文字。

## 一句话公式

一句话只需要包含以下三项中的一到三项：

```text
想画什么 + 在什么地方 + 什么感觉
```

例如：

```text
直接生成一张雪地里的黑色小屋，安静、孤独、像艺术摄影。
```

```text
直接生成一张巨大白色空间中的红色圆球，极简、有强烈阳光和几何阴影。
```

```text
直接生成一张雾中湖边的混凝土长椅，清冷、真实、有很多留白。
```

```text
直接生成一张沙漠里的弧形建筑，温暖、宁静、适合手机壁纸。
```

其余构图、光线、材质、颜色、镜头和真实感细节由 skill 自动补充。

极简不代表只能生成黑白灰、白墙或蓝天建筑。你可以不指定颜色和风格，让 skill 根据主体选择；也可以直接要求完全不同的方向：

```text
直接生成一张黑暗空间中的极窄光缝，只有一个小人物，抽象、神秘。
```

```text
直接生成一张黄色旧墙、绿色树叶和蓝天组成的极简生活摄影，颜色明亮。
```

```text
直接生成一张铺满画面的玻璃窗格，只有一扇窗打开，真实城市摄影。
```

## 想控制得更多

在原句后面增加你在意的内容即可，不需要全部填写：

```text
主体 + 场景 + 感觉 + 时间或天气 + 颜色 + 图片比例 + 不想出现的东西
```

示例：

```text
直接生成一张海边的白色弧形美术馆，黄昏，蓝灰色，安静高级，竖图，不要人物和文字。
```

常用说法：

- 图片比例：横图、竖图、正方形、手机壁纸、电脑壁纸。
- 光线：清晨柔光、正午阳光、黄昏、阴天、雾天、一道光。
- 感觉：安静、温暖、清冷、孤独、神秘、庄重、梦幻。
- 材质：混凝土、石头、玻璃、金属、木头、雪、沙、水面。
- 排除内容：不要人物、不要文字、不要家具、不要鲜艳颜色。

不知道怎么选时可以不写，让 skill 自动决定。

## 用参考图生成

上传参考图后，用一句话说明“保留什么”和“改成什么”：

```text
参考这张图的构图和光线，改成海边的极简美术馆，直接生成图片。
```

```text
保留这张图的大面积留白和小主体，把雪地改成沙漠，其他感觉不变。
```

```text
参考这张图的空间感，不复制建筑，把整体改成冷灰色的混凝土场景。
```

只写“照着这张图做”容易产生误解。最好指出要保留的是构图、光线、颜色、材质或整体感觉。

## 修改已经生成的图片

一次修改一到两个重点，并说明其他内容保持不变：

```text
其他不变，把阳光改成阴天柔光，颜色更冷一点。
```

```text
其他不变，让主体更小、留白更多。
```

```text
其他不变，去掉人物和文字，墙面增加真实的粗糙质感。
```

```text
其他不变，改成 9:16 手机壁纸。
```

## 结果不理想时怎么说

- 画面太乱：`元素太多，只保留一个主体，增加留白。`
- 看起来像假 3D：`减少塑料感，增加真实材质、接触阴影和自然光。`
- 不够极简：`删除装饰和次要物体，强化一个主结构。`
- 主体太大：`让主体只占画面约 15%，其余保留环境。`
- 颜色太艳：`降低饱和度，只保留一个小面积强调色。`
- 光线混乱：`只保留一个主光方向，统一所有阴影。`
- 想继续尝试：`构图不变，再给我一个阴天版本和一个正午硬光版本。`

## 可直接使用的入门句子

```text
使用 $minimal-scene-design，直接生成一张极简建筑摄影作品，你来决定场景，但要安静、真实、有大片留白。
```

```text
使用 $minimal-scene-design，直接生成一张适合手机壁纸的极简自然场景，不要人物和文字。
```

```text
使用 $minimal-scene-design，把我上传的图片变得更极简、更高级，保留原来的主体。
```

```text
使用 $minimal-scene-design，先帮我选择一个最合适的方案，然后直接生成图片，不需要向我解释专业参数。
```
